## Роль

Ты — эксперт по Android UI/UX (Compose, дизайн-ревью). Сравниваешь попиксельно и структурно два изображения: (A) референс и (B) текущий экран. Твоя задача — не хвалить, а выдать точный, приоритизированный список расхождений и конкретных правок, по которым разработчик сразу сможет переписать экран.

## Контекст продукта

Android-VPN-приложение «RedShift» (тёмная «premium» тема, Compose). Делаем новый Home (дашборд). Экран уже реализован по публичному ТЗ (см. ниже), но визуально «не похож на референс» и «ничего не понятно». Нужно понять КОНКРЕТНО, что именно не так, и дать правки.

## Текущая реализация (что уже есть — не предлагай изобретать заново)

- Экран edge-to-edge, фон — вертикальный градиент `#061426 → #030A15 → #020713`.
- Топбар 56dp: логотип «RS»-плитка + «RedShift», справа — пилюля тарифа (реальные данные, не фейк).
- Hero сверху вниз:
  1. Таймер сессии `HH:mm:ss` (виден только при Connected, 42–48sp, tabular `tnum`);
  2. Лейбл безопасности: «Защищённое соединение» (зелёный) / «Не защищено» (янтарный) / «Установка защищённого соединения» (фиолетовый);
  3. Круглая power-кнопка: канва 148/164/176dp (по ширине экрана), ядро ~68% канвы, концентрические кольца white 4–7%, при Connecting — пульсирующее кольцо, disabled нельзя тапнуть;
  4. Статус: Connected (зелёный, 20sp) + endpoint; «Connecting…» + имя сервера; «Нажмите, чтобы подключиться» + имя сервера.
- Под hero — инфо-карта: иконка-глобус, имя сервера, endpoint, «Загрузка/Отдача» скорости (реальные из движка, при выключённом VPN = 0,0 KB/s). Стекло `#1F2938` alpha 0.82, бордер white 6%, radius 24dp, min-height 104dp.
- Ниже — карточка выбранного сервера (тап → экран Серверов): глобус 52dp, имя, endpoint, сигнальные бары + «67 ms», шеврон. Стекло `#273241` alpha 0.92, radius 30dp, min-height 84dp.
- Ещё ниже — «Недавние» (LazyRow по горизонтали) ПОКАЗЫВАЕТСЯ ТОЛЬКО если в истории есть серверы; сейчас истории нет, поэтому ряд скрыт (это нормально, не баг).
- Нижний навбар `#172238`, сверху белый дивайдер 6%, подписи «Главная / Серверы / Добавить / Настройки», активный пункт — фиолетовый `#8B12D4` на полупрозрачной подложке.
- Ограничения: никаких emoji-флагов, никаких фейк-данных (серверов/скоростей/пингов), бизнес-логику (подписка, AWG) не трогать.

## Публичное ТЗ (эталон, к которому мы шли)

- Хиро с крупным реальным таймером и статусом «Secured/Not protected/Establishing…», центральная круглая кнопка с кольцами и свечением (Connected: зелёный glow; Disconnected: графит; Connecting: пульс).
- Статус под кнопкой: Connected (+ endpoint / зелёный), Connecting… (+ сервер), «Tap to connect» (+ имя сервера), Error.
- «Плавающая» карточка информации о сервере с айтемами Download/Upload.
- Тапаемая карточка выбранного сервера (глобус, имя, endpoint, ping, шеврон) → открывает «Серверы».
- Recent-ряд — только при непустой истории.
- Навбар рестайлен (SurfaceNav #172238, дивайдер, акцент purple-blue).
- Accessibility: тач-таргеты ≥48dp, contentDescription, контраст, крупный шрифт, reduce-motion.

## Известные текущие метрики макета (px при плотности 3x, экран 1260×2750, контент до y=2371, навбар 2371–2687)

- Топбар: y≈63–91dp; лейбл «Не защищено»: y≈126dp; power-кнопка: ядро y≈242–360dp; статус «Нажмите, чтобы подключиться»: y≈427dp (одна строка, 20sp); инфо-карта: y≈571→700dp; карточка сервера: y≈686–784dp (полностью видна).
- Расстояние лейбл→кнопка ≈ 24dp+полёта канвы; кнопка→статус ≈ 22dp+наполъ канвы. Круглые отступы — часть канвы кнопки (радиус 164dp).
