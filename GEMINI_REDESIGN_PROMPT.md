## Роль и задача

Ты — senior Android-разработчик и веб-дизайнер уровня Behance. Перепиши UI существующего Kotlin/Compose VPN-приложения **RedShift** полностью: новый визуальный стиль «liquid glass» (жидкое стекло) с 3D-анимациями на уровне **PiplVPN** (`com.piplnetwork.piplvpn`, глянь его скриншоты/стиль), красивая авторизация, лаконичный дашборд. Ядро работает (состояние зафиксировано ниже), баги парсинга и подключения решены — фокус ТОЛЬКО на дизайне и UX UI-слоя. Не менять логику ядра: VPN, sing-box, протоколы — только UI-слой и сопутствующее отображение данных.

## Что за приложение

- **RedShift** — Android VPN-клиент для российской сети RedPill Cloud.
- Стек: Kotlin 2.2.10, Jetpack Compose + Material 3, AGP 9.1.1, minSdk 24, target 36, package `com.aistudio.redshift.rkzvpt`, namespace `com.example`.
- Ядро: **sing-box-lx in-process через JNI** (`libsingbox.so`, 55 МБ в `app/src/main/jniLibs/arm64-v8a/`), работает внутри процесса как `VpnService` в fd-режиме. MTU 1280, TUN `stack: gvisor` (обязательно). `auto_route=false`, `auto_detect_interface=false` (netlink несанкционирован в Android — см. комментарий в генераторе).
- Поддерживаемые протоколы: AmneziaWG, VLESS(+Reality/WS/XHTTP), Trojan, Hysteria2, Shadowsocks, VMess. Живой статус каждого — в таблице «Актуальное состояние».
- Подписка приходит URI-конфигом с сервера `https://redpillcloud.ru/sub/<telegram_id>`. Пользователь авторизуется по Telegram ID.
- Текущий UI: киберпанк-тёмная тема, скрин-структура в `app/src/main/java/com/example/ui/` — `Screens.kt` (главная, онбординг, серверы, подписки, правила, настройки, админка), `Components.kt`, `Models.kt` (state), `Localization.kt`, `theme/`.

## АКТУАЛЬНОЕ СОСТОЯНИЕ (фиксация 08.09.2026)

Ключевой фикс, который сделали до редизайна: **TUN-inbound sing-box в fd-режиме не обрабатывал TCP** (только UDP), поэтому веб не грузился вообще. Решение — `stack: "gvisor"` в `SingBoxConfigGenerator.kt` (`baseTunConfig`, строка ~72). **Не менять stack обратно на "system"** — TCP перестанет работать.

Что проверили живым тестом на реальном устройстве (0.2.8, versionCode 20800, сборка `APP_VERSION=0.2.8; gradlew :app:assembleDebug`, подпись uber-apk-signer, установка через adb):

| Протокол | Статус | Детали |
|---|---|---|
| **NL Trojan** (37.220.84.106:7443) | ✅ работает | TCP-стримы идут (`inbound/outbound connection` в `files/singbox/run.log`), сервер видит ESTAB на :7443, neverssl.com открывается, накоплено 180+ MB |
| **Hysteria2 NL Турбо** (:2443 QUIC) | ✅ по IPv4 / ⚠️ IPv6 | страница по IP `http://34.223.124.45/` открывается; но IPv6-цели дают `ERR_EMPTY_RESPONSE` (серверный dial IPv6 не проходит) |
| **VLESS/Reality «БС- …»** (:7444 и др.) | TCP ✅ / DNS ❌ | HTTP-ответ от сервера получаем, но DNS через него не возвращается → `DNS_LOOKUP_FAILED` (пакеты `1.1.1.1:53` уходят, ответа нет) |
| **AmneziaWG** | не перепроверен | после фикса стека не тестировался (клиентский TUN общий, но AWG-ядро на хосте NL не зависит от JNI) |

Прочие факты для понимания:
- Онбординг показывается снова после каждого `install -r` (флаг «видели онбординг» не персистится) — при редизайне сделай разовую отбивку.
- Выбор сервера в «Серверы» не переподключает VPN сразу — нужно выключить/включить (мелочь UX, оставили как есть).
- Парсер подписки `SubscriptionClient.kt` уже сохраняет `path/host/extra/alpn/flow/sni/pbk/sid/fp` для VLESS и генерирует транспорт `ws|grpc|xhttp` из них (`SingBoxConfigGenerator.buildOutbound`, ~200-228) — плодить дубли не нужно.

## РЕДИЗАЙН: liquid glass + 3D-анимации уровня PiplVPN

Полностью переоформить UI. Стиль-референс: **PiplVPN** — полупрозрачные стеклянные панели, размытие (blur), градиентные обводки, параллакс/3D-повороты при движении, плавные упругие анимации, премиальный онбординг и авторизация. Темы прироритизированы так: дизайн > фиксы > всё остальное. Итоговый экран — «вау».

### Общая дизайн-система
- **Liquid glass**: полупрозрачные «стеклянные» карточки (цвет фона с альфой ~0.35-0.6 + blurBackground/Brush edge + тонкая градиентная обводка 1-1.5dp), лёгкие внутренние тени, отражения/glare-оверлеи.
- **Фон**: глубокий тёмно-сине-фиолетовый градиент + анимированные плавающие светящиеся «пузыри»/пятна света (тёплые оранжево-розовые акценты как в PiplVPN), мягкий parallax при скролле/наклоне.
- **3D-анимации**: главная кнопка подключения — сфера/сфера-реактор с тени и бликом, при подключении — анимированные потоки частиц вокруг, индекс преломления (refraction illusion). Карточки серверов — лёгкий 3D tilt при тапе/наведении.
- **Минимальная палитра**: тёмный фон + 1-2 кислотных акцента (лазурно-синий + неон-оранж), белый текст со степенями прозрачности. Никакой «киберпанк-ряби» и лишней неоновой каши.
- **Сетка Motion**: `spring(dampingRatio=0.7)` для карточек, fade+slide для смены табов, staggered-анимации списков.
- Юзер-потоки той же логики, что сейчас (флоу не менять), но визуально — другой уровень.
- Поддержать `Material 3` темы: и тёмную (основная), и лёгкую-«white glass» как опцию.

## Жёсткие ограничения (НЕ трогать / НЕ менять)
1. Никаких изменений в ядре: VpnService fd-режим, sing-box-lx JNI, MTU 1280, локализация, парсинг конфигов. В частности **TUN `stack: "gvisor"` в `SingBoxConfigGenerator` не менять** и в новых конфиг-правиэ не обходить. Механизм запуска/подключения — НЕ трогать.
2. Не выносить ключи/токены в код/UI; админ-действия — у владельца.
3. Не ломать сборку: тот же AGP/Kotlin/Compose-версии, без новых тяжёлых зависимостей (допустимы: `androidx.compose.material3:material3`, уже используемые; для blur/graphism — `androidx.compose.ui:ui` штатные средства; если нужна сторонняя либа для 3D/blur — минимальная и бесплатная, обоснуй).
4. Репо публичное — никаких реальных секретов, API-ключей, серверных адресов с кредами в коде и коммитах.
5. Сохранить русскую локализацию (Localization.kt) — можно добавить, не удалять.
6. **Текущий работоспособный флоу подключения не ломать.** После редизайна приложение должно также собираться и запускаться; проверка подключения — любым рабочим сервером (NL Trojan).
