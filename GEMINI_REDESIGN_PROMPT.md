## БАГ №1: прочерк вместо данных подписки/срока

Симптом: на главной сверху `SubscriptionInfoBar` показывает план и срок как «—» / «Exp: —», хотя у пользователя активная подписка.

Корень (найден): сервер подписки `https://redpillcloud.ru/sub/<id>` НЕ отдаёт заголовки `subscription-userinfo` и `profile-info`, поэтому `parseSubscriptionUserinfoHeader`/`parseProfileInfoHeader` возвращают null и `profile.expiry=0`. При этом REST API `/api/v1/user/<id>` и `/subscription` РАБОТАЮТ и возвращают правильные данные: `{"subscription":{"tariff":"pro_12m","expires_at":"2027-04-20 17:31:26","status":"active","region":"eu1"}}`.

Задача: сделать надёжный фолбэк в приложении:
1. Сначала попытаться распарсить заголовки подписки (`subscription-userinfo`, `profile-info`, поле `expires_at` в JSON).
2. Если их нет и `userId` из URL подписки — число → дёрнуть `/api/v1/user/<id>` и `/subscription`, взять `tariff`, `expires_at` (формат `"YYYY-MM-DD HH:MM:SS"`), `used`, `total` если есть.
3. Показывать в `SubscriptionInfoBar`: название тарифа, срок в читаемом виде («до 20 апреля 2027» / «осталось N дней»), прогресс-бар израсходованного трафика если доступен.
4. Не ломать AmneziaWG и работу без подписки (ручной импорт сервера).

## БАГ №2: сервера из подписки не работают, работает только AmneziaWG

Симптом: подключение через сервера из подписки (VLESS/XHTTP/WS, Trojan, Hysteria2) не поднимается; AmneziaWG подключается нормально.

Корень (найден): реальные записи vless:// в подписке несут слои и обвесы, которые текущий конвертер выкидывает. Примеры из реальной подписки:

1. `vless://<uuid>@95.129.236.124:443?encryption=none&fp=safari&path=%2Fgateway%2Fv1%2Fws%2F<hex>&security=tls&sni=game-booster.sowt.app&type=ws#БС- 🇳🇱 Nigeria 1`
   → `buildVlessOutbound` (см. строки 196-208) зашивает `path="/"` вместо реального пути из `%2Fgateway%2Fv1%2Fws%2F...`, а парсер `parseVlessUri` вообще не сохраняет `path`.

2. `vless://<uuid>@188.72.103.4:443?alpn=h2%2Chttp%2F1.1&...&type=xhttp&path=%2Fstatic%2Fjs%2Fapp-8d2f%2F&extra=%7B%22host%22...%7D#БС- 🇳🇱 Nigeria 3`
   → конвертер молча превращает `xhttp` в обычный `ws` с `path="/"`, теряя `Host`-хедер, `extra`-параметры и сам транспорт XHTTP.

Задача: исправить парсинг и генерацию так, чтобы из URI сохранялись и попадали в конфиг sing-box:
- `path` (из `%HH`-экранирования — раскодировать),
- `host` и `extra` (для WS/XHTTP — Host-хедер, headers из extra JSON),
- `type=xhttp` → генерировать транспорт `xhttp` (не `ws`),
- `alpn`, `fp`, `sni`, `pbk`, `sid`, `flow`.
- Для Trojan: собрать по аналогии (sni, alpn, fingerprint если есть).
- Для Hysteria2: сохранить password/sni, проверить формат `hy2://`.

Правило: если параметры в URI есть — они ДОЛЖНЫ попасть в конфиг; недопустимо зашивать заглушки (`path="/"`), когда в подписке конкретный путь. Парсеры и генератор — единый контракт, тестируй на реальных строках из примера выше (uuid можно подставить тестовый; не пости секреты в публичный код).

## РЕДИЗАЙН: liquid glass + 3D-анимации уровня PiplVPN

Полностью переоформить UI. Стиль-референс: **PiplVPN** — полупрозрачные стеклянные панели, размытие (blur), градиентные обводки, параллакс/3D-повороты при движении, плавные упругие анимации, премиальный онбординг и авторизация. Темы прироритизированы так: дизайн > фиксы > всё остальное. Итоговый экран — «вау».

### Общая дизайн-система
- **Liquid glass**: полупрозрачные «стеклянные» карточки (цвет фона с альфой ~0.35-0.6 + blurBackground/Brush edge + тонкая градиентная обводка 1-1.5dp), лёгкие внутренние тени, отражения/glare-оверлеи.
- **Фон**: глубокий тёмно-сине-фиолетовый градиент + анимированные плавающие светящиеся «пузыри»/пятна света (тёплые оранжево-розовые акценты как в PiplVPN), мягкий parallax при скролле/наклоне.
- **3D-анимации**: главная кнопка подключения — сфера/сфера-реактор с тени и бликом, при подключении — анимированные потоки частиц вокруг, индекс преломления (refraction illusion). Карточки серверов — лёгкий 3D tilt при тапе/наведении.
- **Минимальная палитра**: тёмный фон + 1-2 кислотных акцента (лазурно-синий + неон-оранж), белый текст со степенями прозрачности. Никакой «киберпанк-ряби» и лишней неоновой каши.
- **Сетка Motion**: `spring(dampingRatio=0.7)` для карточек, fade+slide для смены табов, staggered-анимации списков.
- Юзер-потоки той же логики, что сейчас (флоу не менять), но визуально — другой уровень.
- Поддержать `Material 3` темы: и тёмную (основная), и лёгкую-«white glass» как опцию.
